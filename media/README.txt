Drop audio files here: .wav (8/16/24/32-bit, float), .flac or .mp3, any sample rate,
mono or stereo. They show up under Signal > Source > File and on the Launchpad's
"src: file" / "next file" / "prev file" pads. Files anywhere else on disk can be opened
by typing their path in the File source.

pifx writes a small demo-tone-loop.wav on first run so there is always something to play.
